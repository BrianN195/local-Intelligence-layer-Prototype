## How do I start the Local-intelligence-layer?
- go in the "local-intelligence" Directory
- start the server with "node app.js"
- let the seedScript run "node seedScript.js"

## Is there a Visual of the Agetns and Neighborhoods?
- Yes it is! right click on the index.html and click on "open with Live Server"
- You will see 3x3 neighborhoods with 3x3 Agents inside
- white means inactive, black means active
